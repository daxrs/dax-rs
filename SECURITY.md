# Security Policy

## Supported Versions

dax-rs is in **alpha**. Only the latest release/commit on `main` is supported — please update before reporting an issue.

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Instead, email **info@dax.rs** with:
- A description of the vulnerability and its impact
- Steps to reproduce (proof-of-concept if possible)
- Affected version/commit

We'll acknowledge your report as soon as possible and work with you on a fix and disclosure timeline.
